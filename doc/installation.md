# 🤖 Installation

## 🦾 Déploiement sur AlwaysData

1. Connectez-vous à votre espace **AlwaysData**.
2. Ouvrez la base de données fournie dans **phpMyAdmin**, puis créez les tables et importez les données nécessaires.
3. Mettez à jour la connexion **PDO** dans les fichiers PHP avec les nouveaux paramètres :
	- adresse du serveur
	- nom de la base de données
	- identifiant
	- mot de passe
4. Ouvrez **FileZilla** et connectez-vous au serveur en **FTP** avec les identifiants fournis.
5. Envoyez tous les fichiers du projet dans le dossier **`www/`**.

Une fois ces étapes terminées, le **projet est en ligne**. ✨
